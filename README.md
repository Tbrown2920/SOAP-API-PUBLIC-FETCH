# SOAP-API-PUBLIC-FETCH Reflection
For this assignment, I reviewed the CountryInfoService example and adapted it to consume a different public WSDL—the InterSystem SOAP Demonstration service. Using Python's zeep library and 'helpers.serialize_object ()', I built a client that reads the WSDL contract and converts the XML responses into standard Python dictionaries. I then wrapped that client in a Flask app with a GET route for browser testing and a POST route that handles both form inputs and curl JSON requests. What surprised me was how smoothly Zeep handles the XML conversion behind the scenes, making the process straightforward. My code evolved from a basic script into a safer service once I added input validate 5 digit US Zipcodes and custom error messages joined with '{exc}'. Overall, this assignment gave me a hands on understanding on how a healthcare institution communicates and exchanges data with outside entities where contracts are required.
